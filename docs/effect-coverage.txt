EVERY EFFECT THE 836 CLASS SPELLS USE, AND HOW THE ENGINE RESOLVES IT

Descriptions are the client's own text, translated. #1 / #2 / #3 are the client's own
placeholders: #1 is the effect's diceNum (the low roll, or a spell / summon id), #2 its
diceSide (the high roll, or a grade), #3 its value (a state id, an amount, a percentage).
So "#1-#2 water damage" reads as "9-10" on an effect that rolls 9 to 10.

RESOLVED BY   engine          the engine has a branch for it
              characteristic  no code at all: read from the client's own Effects table
              MISSING         not implemented yet
